# Zeus Workspace
You can find Zeus Documentations in ./docs.

Zeus is a combination of dynamic and static language.

# Explain
Use ZeusCode to explain to the user what the concept is about. The explanation should be clear and concise, providing a brief overview of the topic.

# Modify
Make sure new Zeus syntax is compatible with existing code, and generic enough to be used in various contexts, instead of being too specific to a particular use case. 

Make sure C++ realizations obey the following rules:
  - 带public、private等的 class definitions 需要为其配对缩进，例如public:后续增加一次缩进，而不是和函数同行。
  - 不允许特例化和单文件堆屎山

Zeus Syntax is designed to be intuitive and easy to read, it seems like a mix of Python, C++, JavaScript.
